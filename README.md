# Cardo

Karteikarten-App (Web-App) mit Spaced Repetition, gestaltbaren Ordnern, Farbthemen und Synchronisierung über Supabase.

- `index.html` – die ganze App
- `manifest.json`, `icons/` – App-Name und App-Icon für den Home-Bildschirm
- `sw.js` – sorgt dafür, dass Cardo auch offline startet

Veröffentlicht über GitHub Pages. Daten liegen in Supabase (Tabelle `docs`, pro Person abgesichert).
